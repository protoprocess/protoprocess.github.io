# Charte — logos Proto Process

Référence unique des logos et pictos PP pour les applis, documents et sites.

| Fichier | Usage |
|---|---|
| `logo-pp.png` / `-rect.png` | Logo couleur (carré / horizontal), fonds clairs |
| `*-blanc.png` | Version blanche, fonds sombres |
| `*-noir.png` | Version noire, fonds clairs |
| `*-fond-noir.png` | Couleur sur cartouche noir |
| `picto-pp*.png` | Picto « P » seul (favicon, en-têtes d'applis) |
| `certifs/` | AFAQ ISO 9001, IPC-A-610, IPC |

Sources vectorielles (.ai) : conservées hors Git, chez Olivier.
Convention applis internes : voir `CHARTE_GRAPHIQUE_PP.md` (picto mutualisé dans `<dépôt>/shared/`).
